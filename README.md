# ทำงานอยู่ครับ™ — Totally Working

เว็บ static สำหรับ Stupid Hackathon: YouTube, AI ขี้เกียจ และเพลงเงียบ แสดงทีละแท็บและสลับธีม Windows 95 / XP / 11 โดยคงสถานะ

## เปิดเดโม

ดับเบิลคลิก `run.bat` (ต้องมี Python 3) หรือรันจากโฟลเดอร์นี้:

```powershell
python -B scripts/serve.py --open
```

เปิด http://localhost:8000 หากพอร์ตติดใช้งาน ให้ปิด server เดิมหรือเพิ่ม `--port 8001` ใช้ localhost แทนการเปิด index.html ตรง ๆ เพราะแอปใช้ native ES modules และกล้อง

## สิ่งที่ใช้งานได้

- YouTube ใช้ IFrame API จริง โหลด URL/ID, Play/Pause และปรับ mute ได้ กระพริบหนึ่งครั้งหยุดหนึ่งครั้ง ลืมตาและกลับจากหน้าทำงานไม่เล่นต่อเอง ออกจากแท็บแล้วหยุด
- AI เป็นข้อความตามบท ไม่มี LLM/API มี typing delay, keyword replies และห้องพัก ChatLazy/CodeNap/AutoPause หลังผ่าน CAPTCHA 13 → 1101 และยอมรับ cookies ตอบผิดลองใหม่ได้
- เพลงสมมติทั้งหมด ไม่มี audio source หรือ AudioContext เล่น progress/เปลี่ยนเพลงได้ โหมดห้องสมุดให้พิมพ์ตามข้อความภายใน 10 วินาทีเพื่อเปลี่ยนระดับที่แสดง ยังได้ยิน 0% ทุกกรณี
- ปุ่ม “ทำงานอยู่ครับ!” หรือ B เปิดรายงาน Q4 เต็มหน้าทันที ซ่อนและทำหน้าอู้ inert หยุด player และ timers โดยเก็บ draft, ห้อง, CAPTCHA, theme, tab และเวลาโจทย์ไว้
- เมื่อข้อมูลตรวจคนพร้อมและไม่พบคนต่อเนื่อง 2 วินาที กด × หรือ Escape กลับเองได้ หากข้อมูลกล้องไม่พร้อมต้องกด × แล้วยืนยันด้วยตนเอง Escape ไม่ข้ามเงื่อนไข Hotkeys ไม่ทำงานขณะพิมพ์หรือใช้ IME
- เปิดเว็บอื่นจาก settings ได้เฉพาะ http/https การฝังขึ้นอยู่กับเว็บ หากไม่แสดงให้กดเปิดแท็บภายนอก ระบบไม่ควบคุมแท็บภายนอก เมื่อเข้าหน้าทำงาน iframe ทั่วไปถูก unload และโหลดใหม่ตอนกลับ ไม่รับประกัน state ของเว็บนั้น

## กล้องและการตรวจจับ

เปิด settings แล้วกด “เปิดกล้องและเริ่มตรวจจับ” ระบบจะโหลด MediaPipe FaceMesh สำหรับตรวจตาและคำนวณ EAR พร้อม TensorFlow.js + COCO-SSD สำหรับตรวจคนตามวิธีใน [GitHub repo StupidX](https://github.com/ssiriwan/StupidX) โดยอัตโนมัติ ตรวจพบตั้งแต่ 2 คนหรือ 2 ใบหน้าจะเรียกการเตือน ไม่ต้องตั้งกรอบที่นั่ง/พื้นที่เฝ้าระวังหรือปรับความไวเอง

สคริปต์ตัวตรวจโหลดจาก CDN และ weights ของ COCO-SSD โหลดจาก Google Storage เมื่อเริ่มกล้อง วิดีโอประมวลผลในเบราว์เซอร์และไม่ส่งไป backend ของแอป ถ้าตัวตรวจล้มเหลวหรือข้อมูลเก่า ระบบจะบอกว่าข้อมูลไม่พร้อม แทนการแจ้งว่าพื้นที่ปลอดภัย

เดโมสำรอง: settings → เปิดโหมดจำลอง → จำลองกะพริบ หรือจำลองคนเข้ามา ใช้ event path เดียวกับกล้องจริงและระบุชัดว่าเป็นการจำลอง

รีเซ็ตเดโมใน settings ล้างสถานะฟีเจอร์และผลตรวจโดยไม่สร้าง listener/timer/stream ซ้ำ การตรวจคนใช้จำนวนคนและใบหน้าตามเฟรมกล้อง ไม่ใช่การยืนยันตัวบุคคล ต้องทดสอบความแม่นและความเร็วบนกล้องจริงก่อนเดโม

## ตรวจโค้ด

ต้องมี Node.js สำหรับตรวจและทดสอบ ไม่มี npm dependency และไม่ต้อง npm install:

```powershell
node scripts/check.mjs
node --test tests/*.test.mjs
```

โค้ดหลัก: `src/app.js` รวมฟีเจอร์, `src/core/` controller/timers, `src/features/` player/AI/music/launcher, `src/ui/` shell/รายงาน, `src/vision/` กล้อง, FaceMesh และ COCO-SSD, และ `styles/` ธีม

ผลตรวจรอบนี้: Node tests 41/41 ผ่าน, syntax/import/HTML checks ผ่าน (18 modules, 19 DOM IDs), และ git diff check ผ่าน การตรวจภาพจาก webcam จริงยังต้องทำใน browser ที่อนุญาตกล้อง; in-app browser ก่อนหน้านี้ส่งเฟรมขนาด 0×0
