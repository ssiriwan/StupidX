# 🛡️ BossGuard 3000 (Stupid Hackathon Edition)
> **"เว็บอู้งานระดับพระกาฬ ที่ใช้พลัง AI ขั้นสูงเพื่อการดูคลิปและสลับจอหนีเจ้านายแบบไร้รอยต่อ"**

---

## 🌟 ฟีเจอร์หลัก (Core Features)

1. **Anti-FOMO Eye Tracker (หลับตา/กระพริบตา = หยุดคลิปทันที)**
   - คำนวณค่า **Eye Aspect Ratio (EAR)** แบบเรียลไทม์ผ่าน **MediaPipe FaceMesh**
   - เมื่อเปลือกตาปิดลง คลิป (YouTube หรือไฟล์ในเครื่อง) จะหยุดเล่นทันที เพื่อป้องกันไม่ให้คุณพลาดช็อตสำคัญแม้แต่เสี้ยววินาทีเดียว!
   - เมื่อลืมตาขึ้นมา คลิปจะเล่นต่อโดยอัตโนมัติ

2. **The Boss Radar (ระบบเรดาร์ตรวจจับเจ้านาย)**
   - ใช้ **COCO-SSD (TensorFlow.js) + Face Mesh** ตรวจจับคนในกล้อง
   - เมื่อมีบุคคลที่ 2 เดินตัดเข้ามาในมุมกล้อง (Person Count >= 2 หรือพบใบหน้าเพิ่มเติม) ระบบจะสั่ง:
     - 🔇 **Mute เสียงทุกอย่างทันที 100%** ไม่ให้มีเสียงคลิปหลุดรอด
     - 💻 **เด้งหน้าจอพรางตัว (VS Code Camouflage) ทับเต็มจอทันที!**
   - มี **Safety Cooldown (หน่วงเวลา 3 วินาที)** หลังจากเจ้านายเดินออกไป เพื่อกันเจ้านายหันควับกลับมามอง

3. **HackerTyper Keyboard Generator**
   - ระหว่างที่หน้าจอเป็นโหมดพรางตัว (VS Code) เพียงแค่กดแป้นพิมพ์อะไรก็ได้มั่วๆ หน้าจอจะพิมพ์โค้ด C++/Rust คุณภาพสูงออกมาแบบไฟแลบ พร้อมเสียงคีย์บอร์ดเสมือนจริง

4. **Stupid Analytics Dashboard**
   - แสดงสถิติว่าคุณกระพริบตาไปกี่ครั้ง เซฟเนื้อหาคลิปไม่ให้พลาดไปกี่วินาที และหลบเจ้านายสำเร็จกี่ครั้ง

## 🚀 วิธีเปิดใช้งาน (Quick Start)

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์รัน
ดับเบิ้ลคลิกที่ไฟล์ `run.bat` ในโฟลเดอร์นี้ ตัวโปรแกรมจะเปิดเบราว์เซอร์ไปที่ `http://localhost:8000` ให้อัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal / PowerShell
```bash
python -m http.server 8000
```
แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:8000`

## ⌨️ คีย์ลัดสำหรับการเดโมบนเวที (Demo Hotkeys)
- **กดปุ่ม `B`**: สลับโหมดเจ้านายมา (Emergency Panic) ทันที (สำหรับใช้เดโมบนเวทีให้กรรมการดูโดยไม่ต้องรอคนเดินผ่าน)
- **กดปุ่ม `Escape`**: ออกจากโหมดพรางตัวกลับสู่โหมดอู้งาน
- **กดแป้นพิมพ์ใดๆ ในโหมดพรางตัว**: พิมพ์โค้ด HackerTyper รัวๆ
